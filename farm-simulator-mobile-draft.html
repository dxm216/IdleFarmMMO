    Developer setup

    Supabase setup — anon key, database SQL, Google login

    One-time setup, in order:

    1. Anon key: in the Supabase dashboard go to Settings → API and copy the anon public key. Paste it into the SUPABASE_ANON_KEY constant at the top of this file's script (the project URL is already set). The anon key is a publishable client key — safe to ship in this file; the database is protected by Row Level Security, below.
    2. Database: in the Supabase dashboard open the SQL Editor, paste the SQL below, and run it once. It creates the profiles, farm_saves, and high_scores tables with Row Level Security: players can only read and write their own profile and farm save, and high scores are readable by everyone but can only be added under your own account.
    3. Email login: works out of the box (Auth → Providers → Email). New accounts get a confirmation email by default; for testing you can switch off “Confirm email” in that provider so new accounts can log in right away.
    4. Google login: create an OAuth client in Google Cloud Console, then in the Supabase dashboard go to Auth → Providers → Google, switch it on, and paste the Google client ID and secret. Also add this page's hosted URL under Auth → URL Configuration → Redirect URLs. Until that is done, the “Continue with Google” button shows a clear “not set up yet” message instead of failing silently.
    5. Hosting: this login build is meant to be exported and hosted on your own static host (for example Netlify Drop) — it is the same single file.

    SQL — run once in the Supabase SQL Editor:

    -- Farm Simulator — Supabase schema
-- Tables: profiles, farm_saves, high_scores (with Row Level Security)

create table if not exists public.profiles (
  id uuid primary key references auth.users(id) on delete cascade,
  email text,
  display_name text,
  created_at timestamptz not null default now()
);
alter table public.profiles enable row level security;
create policy "profiles: read own" on public.profiles
  for select using (auth.uid() = id);
create policy "profiles: insert own" on public.profiles
  for insert with check (auth.uid() = id);
create policy "profiles: update own" on public.profiles
  for update using (auth.uid() = id) with check (auth.uid() = id);

create table if not exists public.farm_saves (
  user_id uuid primary key references auth.users(id) on delete cascade,
  save jsonb not null,
  updated_at timestamptz not null default now()
);
alter table public.farm_saves enable row level security;
create policy "farm_saves: read own" on public.farm_saves
  for select using (auth.uid() = user_id);
create policy "farm_saves: insert own" on public.farm_saves
  for insert with check (auth.uid() = user_id);
create policy "farm_saves: update own" on public.farm_saves
  for update using (auth.uid() = user_id) with check (auth.uid() = user_id);

create table if not exists public.high_scores (
  id uuid primary key default gen_random_uuid(),
  user_id uuid not null references auth.users(id) on delete cascade,
  display_name text,
  lifetime_earned numeric not null default 0,
  created_at timestamptz not null default now()
);
alter table public.high_scores enable row level security;
create policy "high_scores: read all" on public.high_scores
  for select using (true);
create policy "high_scores: insert own" on public.high_scores
  for insert with check (auth.uid() = user_id);
